# Java WebApp CI/CD on AWS EKS

End-to-end DevOps project deploying a Java web application using Jenkins, Docker, and Kubernetes on AWS EKS.

### 🛠️ Tech Stack
- **CI/CD:** Jenkins, GitHub Webhooks, Jenkinsfile
- **Containerization:** Docker, DockerHub
- **Orchestration:** Kubernetes, AWS EKS
- **Cloud:** AWS EC2, EKS, ELB, IAM, VPC
- **Application:** Java 11, Maven, JSP, Tomcat
- **IaC:** Kubernetes YAML, Dockerfile
